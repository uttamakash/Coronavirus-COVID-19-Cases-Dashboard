🦠 Coronavirus (COVID-19) Cases Dashboard
📊 Interactive Data Visualization using Tableau
📘 Project Overview

The Coronavirus (COVID-19) Cases Dashboard is an interactive data visualization project built using Tableau.
It analyzes global COVID-19 data to provide insights into the number of confirmed cases, deaths, and recoveries across various countries and continents.

The dashboard enables users to explore data dynamically through maps, charts, and filters — helping researchers, policymakers, and the public better understand the spread and impact of the pandemic.

🎯 Objectives

To visualize the global spread of COVID-19 in an interactive and user-friendly format.

To analyze trends, patterns, and regional variations in confirmed cases, deaths, and recoveries.

To support data-driven insights for better public health understanding and decision-making.

🧠 Key Features

🌍 Global Map View: Displays country-wise case distribution using color-coded intensity.

📈 Time-Series Analysis: Tracks daily and cumulative trends over time.

⚖️ Comparative Visualization: Compare multiple countries or continents interactively.

🩺 Metrics Dashboard: Includes key performance indicators (KPIs) such as fatality rate, recovery rate, and active cases.

🔍 Dynamic Filters: Explore data by region, date range, and case type (confirmed, deaths, recovered).

📋 Design Flow

Data Collection: Acquired global COVID-19 datasets from trusted sources.

Data Cleaning: Removed inconsistencies, missing values, and formatted data properly.

Import to Tableau: Loaded processed data for visualization.

Dashboard Design: Created interactive charts, KPIs, and maps.

Publishing: Exported and shared dashboard for public use and analysis.

📈 Results & Insights

The United States reported the highest total confirmed cases globally.

Multiple waves were observed, corresponding to variant outbreaks.

Recovery rates increased significantly after vaccination rollouts.

Data visualization helped identify regional disparities in healthcare response.
